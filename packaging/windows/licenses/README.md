# Tcl license included in portable archives

`Tcl-8.6.15-LICENSE.txt` is the unchanged license from the upstream Tcl 8.6.15 tag:
https://github.com/tcltk/tcl/blob/core-8-6-15/license.terms

SHA256: `c0a69a2bfd757361ec7e6143973b103c90409316b49e9c88db26ad6388e79f16`

The pinned Windows Python 3.13.15 build supplies Tcl 8.6.15. The legacy v2.0.0
release provided this license as a separate asset. New portable ZIPs include it
inside their root so it travels with the application. Other original licenses
remain in the frozen bundle; this file does not replace them.
