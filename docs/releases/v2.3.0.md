# v2.3.0 · MatchAll

Python / Windows **2.3.0**；Android 源码版本 **1.1.1 / versionCode=7**。本版在 v2.2.0 基础上修复通知可靠性并新增可选 SMTP 邮件通知。实际可下载资产仅以本版公开 Release 清单为准；版本 PR、tag、Actions artifact 与草稿都不是公开发行完成。

## 变化

- 修复通知 dry-run 污染正式每日标记：成功或失败的模拟发送均不再阻止后续真实通知。
- 通知子进程默认总超时从 60 秒调整为 120 秒，`SWUDK_NOTIFY_SEND_TIMEOUT` 可设置为 30–180 秒整数；配套 unit 外层默认超时为 210 秒。非法配置在启动及写入标记前拒绝，不输出配置值。
- 新增 opt-in SMTP 邮件传输，支持验证证书的 STARTTLS / implicit TLS、独立每日防重复标记、脱敏异常、受限网络及总进程超时。默认仍为 Telegram；不自动启用邮箱、不自动重发结果未知的消息。
- Soup Sieve 升级至 4.1，修复旧 2.9.2 版本审计发现的漏洞；同步 Android 依赖和预期许可清单。

## 邮件配置与验证边界

见[邮件通知指南](../email-notifications.md)。每次调用选择一种传输；同时使用 Telegram 与邮件时需单独调用和各自配置。SMTP 密码仅由安全配置注入，不进入仓库、浏览器、日志或问题单。

邮件 dry-run 只验证配置，**不连接 SMTP、不验证账号和网络、不证明投递**。SMTP 接受也不等于收件箱送达。本版没有真实邮件投递验收；没有据此声称修复了 OpenClaw 冷启动耗时根因。

发布前核心变更已通过 1325 项本地测试（7 项跳过）及对应提交跨平台 CI；这些是源码检查，不代替新版本最终产物验收。最终发行以精确 tag commit 的流水线、各包内 BUILD-INFO、SHA256、Android 签名与验收记录为准。

Windows 未获 Authenticode 签名；macOS 为 ad-hoc 签名、未公证预览。学校真实登录/实际签到、Android 16 KB 真机和实体 Mac 干净用户验收不由合成测试证明。只应在本人在寝且符合学校规定时使用。
