# v2.0.0 发布说明

本源码版本为 **2.0.0**，发布目标是在同一 tag 下提供 Python/CLI 分发包与 Windows x64 **未签名桌面预览版**。实际发布状态、完整资产清单、tag commit 和对应 CI run 以本仓库的 [GitHub Releases](https://github.com/Maximora-byte/swu-checkin/releases) 为准；本文件不表示发布或所有平台验收已经完成。

## 相对 v1.1.5 的变化

- **Windows 中文桌面界面**：新增登录检测、只读检测、显式保存账号、确认后的手动签到及默认关闭的可选定时任务。保存的账号与密码使用当前 Windows 用户 DPAPI 保护；打开窗口不会连接学校或自动签到。
- **独立应用与安装包**：冻结应用包含 Python、Tk/Tcl、OCR 模型、时区和证书等资源，无需用户另装 Python 或 uv；当前用户安装、不要求管理员权限。完整 onedir 布局及安装、卸载和迁移边界见 [桌面指南](../windows-desktop.md)。
- **保守的任务管理**：桌面定时任务使用当前用户、最低权限，默认只读模式，正式自动签到需要单独授权。旧 `SWUCheckin-Daily` 任务仍登记时拒绝启用新任务；状态无法确认时锁定调度控件，不把未知结果当作成功。
- **共享正式执行锁**：CLI 与桌面共用正式执行边界，避免同一锁域内的手动/定时流程并发提交；不会协调不同机器或不同锁路径。
- **传输与状态加固**：业务 API 和 token exchange 拒绝重定向，避免向重定向目标转发认证材料或表单；本地历史状态先按结构验证，损坏或不合法的旧记录不会带入新的结果。
- **构建与文档**：新增 Windows 构建来源、依赖/许可信息、SHA256 清单及隔离安装/GUI/卸载测试；更新 CLI、Actions、Windows、systemd、安全和故障排查说明。

主要变更：[PR #33](https://github.com/Maximora-byte/swu-checkin/pull/33)（桌面与运行时加固）、[PR #34](https://github.com/Maximora-byte/swu-checkin/pull/34)（全套文档对齐）。现有 CLI 业务状态码和 JSON `schema_version=1` 契约继续适用；版本号提升不代表桌面已通过稳定版验收。

## 交付目标与校验

发布页应明确列出可用的交付物，未列出或构建失败的资产不能视为已发布：

- Python wheel：`swu_checkin-2.0.0-py3-none-any.whl`
- Python 源码分发包：`swu_checkin-2.0.0.tar.gz`
- Windows 当前用户安装程序：`SWUCheckin-2.0.0-win-x64-Setup.exe`
- Windows 完整 onedir 压缩包：包含整个 `SWUCheckin/` 目录与全部运行资源；不能只复制其中的 EXE
- Windows 来源材料：`BUILD-INFO.json`、`TOOLCHAIN.txt` 与原始 `SHA256SUMS.txt`；应核对应用版本、tag commit、干净源码状态及构建 run
- 上传文件校验值：重新打成 ZIP 的文件需另算 SHA256；构建目录内的清单不自动覆盖新 ZIP

Python Release 工作流只自动创建 wheel/sdist Release，Windows 资产需另行核对来源后附加。GitHub 自动生成的 Source code ZIP/tar.gz 是仓库源码，既不是 Windows 安装包，也不是上述已验证 Python sdist。Actions artifact 仅保留 14 天，不是长期下载地址。校验值和来源元数据不是数字签名，也不构成跨机器逐字节可重现的承诺。

## 升级与迁移

- **源码/CLI、Actions 与 systemd**：选择已确认发布的 tag，同时使用该 tag 的源码、文档、`uv.lock`、工作流/部署文件。不要将 `main` 的版本字符串或单个新文件当作完整升级。升级前按对应指南停用调度并等待已运行任务结束，升级后先做只读诊断，再恢复原先有意启用的任务。
- **旧 Windows Python 脚本迁移**：先删除旧任务登记，保留需要的设置，再按 [迁移指南](../windows.md) 安装桌面版。旧卸载器会递归删除与桌面共用的 `%LOCALAPPDATA%\SWUCheckin`，不要在已保存桌面配置后用它迁移。
- **桌面预览升级**：关闭应用并保持安装路径稳定；核对原有调度和设置。安装不会自动注册任务；桌面卸载默认保留用户配置，并尝试只删除本程序的 `SWUCheckin-Desktop` 任务。

## 验证范围与已知限制

- Windows 历史 CI 已覆盖 Windows Server 2022 x64 上的冻结离线自测、隔离安装、GUI 关闭/重开、卸载及独立无害计划任务注册/查询/删除。发布应引用**本次 tag commit** 的检查记录，不能把历史绿色结果算作本次验证。
- **干净 Windows 10/11 x64 标准用户验收仍未完成**；构建机隔离目录与精简 PATH 不等于全新用户或无开发环境。桌面产物未签名，可能遇到 SmartScreen/安全软件提示；不要关闭防护或绕过安全警告。
- 未以真实学校账号登录或提交签到作为发布测试。计划任务依赖用户登录会话、电源、网络与有效认证，不能保证学校端成功。程序使用学校记录的寝室坐标，不测量真实 GPS，也不证明本人在寝；仅在符合学校规则时使用正式签到。
- 现有 GitHub Actions 签到工作流存在已记录的边界：成功状态 JSON 若伴随非零 CLI 退出码，“执行签到” step 会失败，但后续邮件条件与最终状态只看业务码，最终 job 仍可能显示成功。必须同时查看该 step 的 outcome 与退出码；本版本未修复此组合，见 [Actions 指南](../../GITHUB_ACTIONS.md)。
- 普通 CI 的 `quality` 不包含独立 Windows desktop 构建；Python Release 检查也不覆盖普通 CI 的所有平台、systemd、权限与审计项目。发布证据应分别说明，见 [开发、CI 与发布](../development.md)。
