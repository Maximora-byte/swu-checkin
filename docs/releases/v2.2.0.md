# v2.2.0 · MatchAll

本版提供 Python / Windows **2.2.0** 和 Android **1.1.0 / versionCode=6**。本次汇总 v2.1.1 之后的安全修复、通知隔离、核心优化与界面更新；macOS 15 两架构继续提供预览附件。

## 变化

- Windows/macOS 桌面采用深绿页头、状态胶囊、双栏卡片、分角色按钮和可滚动运行记录，调整 macOS 钥匙串操作布局。
- Android 状态卡和查询/确认步骤更清楚，只有确认待签到后才强调手动签到。顶部日期按北京时间显示，前台跨午夜和后台恢复时刷新，保留大字号单行处理。
- 复用已校验的学生身份、缓存 OCR 引擎，精简实际登录使用的 DES 路径；旧 `get_info` 模块和兼容入口保留并标记弃用。提交失败仍只读回查，不自动重复提交。
- CLI 重试在基础退避上增加 0–25% 抖动；默认两次实际等待为 8–10 秒、16–20 秒。Python API 默认不增加抖动，probe 不运行外层重试。
- 通知发送前先记录送达未知隔离状态，失败或超时后不盲目重发；配套 systemd unit 清理整个服务 cgroup。升级时须同时更新源码、锁文件和 unit，历史实例不会自动部署。
- 更新 Pillow 13.0.0、certifi 2026.10.18、filelock 4.2.1 和 msgpack 1.2.3；每个最终包仍以自身锁文件、许可清单和审计结果为准。

## 验收与支持范围

最终资产的源码 commit、版本、签名、许可和 SHA256 以本版 `ASSET-MANIFEST.json`、`BUILD-INFO` 和 Android 验收报告为准。版本 PR、tag 构建、CI debug 与本机持久签名包分别记录来源和测试，不将历史包的通过数计入本版。

Android 当前 debug 每安装状态 10 项测试，持久签名 release 每状态 9 项；覆盖前台跨日、后台恢复且 Activity 不重建、异地时区、合成登录/确认/取消和加密保存。实际执行结果以本版报告为准。业务自动验收使用合成账号；公共 HTTPS 检测不访问学校接口，不代表真实学校登录或实际签到已经验证。

Windows 仍未获得 Authenticode 签名；macOS 附件仍为 ad-hoc 签名、未公证预览，实体 Mac 干净用户验收未完成。Android 不支持 32 位，16 KB 真机及实际签到没有本版验收证据。技术提交成功不能证明本人在寝，请仅在本人在寝且符合学校规定时使用。

旧 tag 和发行资产保持原始字节，不覆盖、不重标。本次不上传 PyPI，也不自动部署任何服务器。
