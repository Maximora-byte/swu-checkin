# v2.1.0 预发布说明

本版本以 GitHub **Pre-release** 分发，Python/桌面数字版本为 **2.1.0**。Windows 与 macOS 保留预览声明，Android APK 暂不公开。最新稳定版本仍是 [v2.0.0](https://github.com/Maximora-byte/swu-checkin/releases/tag/v2.0.0)，旧 tag 与文件保持原样。

## 相对 v2.0.0 的变化

- Actions 以执行 step outcome、CLI exit code 和严格业务结果共同判定成功，修复成功 JSON 配合非零退出码被误记成功的问题；异常通知不会改写失败结论。
- 共享认证新增人工验证码回调接缝，保留同 session 的图片、原 OAuth/CAS 主机/跳转/state/ticket 校验，取消或异常不回退 OCR。原 CLI/桌面默认 OCR 行为沿用。
- Windows 增加独立 Portable ZIP、完整中文离线说明、来源/哈希与受限 token 解压 smoke；安装器、账号 DPAPI 和默认关闭的任务行为沿用。
- macOS 15 新增 arm64 与 Intel 手动 `.app` 预览、显式系统钥匙串、内存 token 和无后台任务；两架构分别原生构建，不声明 universal2。
- Android 新增人工验证码、Keystore 加密账号、查询/只读诊断、本人在寝确认后的单次手动提交与服务端回查。0.1.1-preview 独立正式包名和持久签名候选，与旧 debug 预览共存。
- 发布流程新增只读 PR/手动预检、同源多平台构建、实际用户包审核、固定发行说明、明确 Pre-release 与已有 Release 拒覆；修复 Windows 归档路径安全校验。
- 分发材料补充项目、实际 Python/Tcl/Tk、平台运行库、依赖与 vendor 的版权原文、notice 和逐文件清单，最终产物须再次核验实际字节。

对应已合并功能详见 [发布准备](https://github.com/Maximora-byte/swu-checkin/blob/v2.1.0/docs/releases/release-readiness.md)。CLI 状态码和 JSON `schema_version=1` 保持原契约。所有客户端共用认证与业务核心，不测量实际 GPS，技术成功不能证明本人在寝；正式提交仅在本人确实在寝且符合学校规则时使用。

## 升级与保留的限制

- Python/systemd/Actions 使用 `v2.1.0` tag 的完整源码、文档、workflow 和 `uv.lock`，升级前停用已有任务并按各部署指南只读复核。
- Windows 安装版与 Portable 共用当前用户数据与任务；更新/移动前关闭已启用任务和应用，不混用新 EXE 与旧 `_internal`。Portable 账号不随目录跨电脑迁移。
- macOS 更新可能重新触发钥匙串授权；删除 `.app` 不自动清除已存账号。没有 Developer ID/公证，不提供绕过 Gatekeeper 的步骤。
- Android 正式包和旧 debug 包不是覆盖升级关系；账号密文绑定包名/AAD/设备 Keystore，须在新包重输。持久证书同版本覆盖与合成账号保持由独立验收检查，不声明旧包/任意跨版本迁移已经验证。
- Android 私钥/DPAPI 密码不公开。本轮受保护本机备份及恢复副本实际签名已通过；维护者公开 APK 前仍须完成离机保管和恢复方案，本轮未验收异机签名恢复。公开证书 SHA256 为 `77ad72b44323fa7917470442e21fb258b5b8bc8a367e87c83ba6fa22d08f811a`，实际包必须匹配。
- 真实学校账号认证/签到、16 KB 实体手机、实体 Mac 干净用户验收和干净 Windows 10/11 标准用户验收仍未完成。合成数据、公共 HTTPS、模拟器和云端 runner 测试不替代这些项目。
