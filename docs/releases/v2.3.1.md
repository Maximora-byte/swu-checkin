# v2.3.1 · MatchAll

Python / Windows **2.3.1**；Android 源码版本 **1.1.2 / versionCode=8**。本版在 [v2.3.0](v2.3.0.md) 基础上更新晚间自动打卡排班并增强验证码瞬态异常重试与脱敏诊断。实际可下载资产仅以本版公开 Release 清单为准；版本 PR、tag、Actions artifact 与草稿都不是公开发行完成。

## 变化

- **调整每日晚间三次打卡调度**：北京时间每日自动运行时间由原 `21:15`、`21:45` 调整为 **21:10、21:29、21:45**（UTC `13:10`、`13:29`、`13:45`），覆盖 systemd timer、GitHub Actions 工作流、Windows 桌面计划任务及安装脚本；后续触发会自动识别已签到状态。
- **验证码 HTTP `412` 纳入瞬态网络异常重试**：在 `_fetch_captcha()` 中将 HTTP `412` 与 `{408, 425, 429}` 及 `5xx` 同等归类为 `AuthFailureReason.NETWORK_ERROR`，使 `CheckinService` 可按既有退避策略重试恢复，同时保持 fail-closed（不进入 OCR、手工验证码回调或登录 `POST`）。
- **新增 `OAuthDiscoveryDetail(StrEnum)` 安全诊断码**：为 `OAuthDiscoveryError` 增加受控固定枚举 `detail` 分类，`login.py` 仅输出固定枚举值而不输出异常原文、URL、凭据或令牌。

- Windows x64：`SWUCheckin-2.3.1-win-x64-Setup.exe` / `SWUCheckin-2.3.1-win-x64-Portable.zip`。
- macOS 15 arm64 / x86_64：对应 `SWUCheckin-2.3.1-macos15-*-preview.zip`，仍为未公证预览。
- Android 正式候选名为 `SWUCheckin-1.1.2-android.apk`；只有同源持久证书签名、签名/来源/许可及独立验收报告齐全后，才能加入正式发布。CI 临时 debug APK 不作为正式下载。升级保留同包名、原持久证书，不卸载清数据，不创建替代证书。

服务器部署须同时核对源码、锁文件及 systemd unit / timer 配置；不要覆盖现有凭据或防重复标记。旧版 tag/资产保持原始字节，不重标。此发行流程不自动部署服务器、不上传 PyPI。

## 验证边界

发布前变更已通过对应 PR 的跨平台 CI（含 `linux-quality`、`windows-quality`、`package-quality` 与发布预检）及适用本地检查；源码检查不代替新版本最终产物验收。最终发行以精确 tag commit 的流水线、各包内 BUILD-INFO、SHA256、Android 签名与验收记录为准。

Windows 未获 Authenticode 签名；macOS 为 ad-hoc 签名、未公证预览。学校真实登录/实际签到、Android 16 KB 真机和实体 Mac 干净用户验收不由合成测试证明。只应在本人在寝且符合学校规定时使用。
