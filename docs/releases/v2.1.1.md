# v2.1.1 · MatchAll

本版提供 Python / Windows 2.1.1 和 Android 1.0.0，软件开发者与发行者统一为 **MatchAll**。保留原始 MIT 版权和第三方许可，仓库地址、应用 ID、Windows 安装标识与 Android 持久签名保持连续。

## 下载与首次使用

从 [本版发布页](https://github.com/Maximora-byte/swu-checkin/releases/tag/v2.1.1) 下载对应文件，并核对 SHA256SUMS.txt。不要安装 CI 测试 APK 或把源码 ZIP 当作安装包。

| 平台 | 文件 | 首次使用 |
| --- | --- | --- |
| Android 7.0+，64 位 | SWUCheckin-1.0.0-android.apk | 手机安装后打开 SWU 查寝，输入校园账号，先点“查询今日状态”，验证码自行填写 |
| Windows 10/11 x64 | SWUCheckin-2.1.1-win-x64-Setup.exe | 按当前用户安装，从开始菜单打开；无需 Python、uv 或 OCR 下载 |
| Windows x64 免安装 | SWUCheckin-2.1.1-win-x64-Portable.zip | 全部解压，运行 SWUCheckin/SWUCheckin.exe；不要只复制 EXE |
| Python CLI | swu_checkin-2.1.1-py3-none-any.whl / .tar.gz | 使用 Python 3.13；依赖安装与 setup/probe 见快速上手 |
| macOS 15 arm64 / x86_64，预览 | SWUCheckin-2.1.1-macos15-架构-preview.zip | 选择对应架构；仍未通过苹果公证，系统信任限制见 macOS 指南 |

Android 沿用原创图标、浅深色卡片、大字号适配和密码显隐。账号默认不保存，可主动开启 AndroidKeyStore 加密保存；打开应用不会联网或自动签到。Windows 默认不启用计划任务，须单独配置和授权。

2026-10-03，账号持有人自行在已安装的 0.1.2-preview 真机输入真实校园账号，反馈查询成功，显示“今日状态暂无签到任务”。这是同一认证/业务核心的真实只读查询反馈，未执行真实签到；新发行包仍独立验收版本、签名和运行。

## 升级与校验

Android 为 **1.0.0 / versionCode=5**，正式包名 io.github.maximorabyte.swucheckin。旧 0.1.2-preview 用户直接覆盖安装，不先卸载或清数据；同设备账号存储保持原包名和密钥绑定。旧 .feasibility debug 包可以共存，账号须自行重输。证书 SHA256：

`77ad72b44323fa7917470442e21fb258b5b8bc8a367e87c83ba6fa22d08f811a`

备份采用独立密码加密的 PKCS12，在维护者指定的离机 USB 盘保存，并验证恢复签名；密码由本人本机输入。发行只附公开证书，私钥和密码不上传。

Windows 升级前关闭应用；Portable 用户保持既有计划任务所引用的目录，账号保存在当前 Windows 用户目录。旧版本 tag 和资产保留原始字节，不覆盖或重标。

Release 的 ASSET-MANIFEST.json / SHA256SUMS.txt 记录最终资产来源与字节。Android-ACCEPTANCE.json 记录最终 APK 的来源、非调试状态、许可、16 KB 原生/ZIP 对齐、模拟器与保持用户数据的真机检查；CI 的临时 debug 测试另行记录，不合计为同一包的通过数。

## 支持范围

Windows 尚未获得 Authenticode 签名，首次下载/安装可能出现系统提示。macOS 附件继续为 ad-hoc 签名、未公证预览，不因 Release 正式属性改变；实体 Mac 干净用户验收尚未完成。Android 不支持 32 位设备，16 KB 真机与实际签到没有验收证据。“暂无签到任务”是学校接口的正常结果，不应为测试制造任务或提交。

本工具使用学校记录的宿舍坐标，不测量真实 GPS。只有本人在寝且符合学校规则，才可主动确认单次提交；技术成功不证明人在寝。
