# Android 0.1.2-preview 界面更新（2026-10-03）

Android 独立版本为 **0.1.2-preview / versionCode=4**。Python/桌面保持 2.1.0，已公开的 v2.1.0 tag 和 Release 资产保持原来的内容；本轮不发布新的 Release 或公开 Android APK。

## 界面变化

- 主页面使用深绿、暖白与薄荷色，今日状态、校园账号、操作和帮助分别呈现为卡片；查询是主要操作，签到继续要求查询后的本人确认。
- 浅色与深色主题跟随系统，状态栏和导航栏图标配合主题；支持滚动、大字号和输入法避让。
- 密码默认隐藏，增加显隐按钮。读取/清除账号、开始查询或页面重建后恢复隐藏；账号页继续禁止截图/录屏。
- 验证码和确认框使用同一套圆角、配色和间距；输入法支持跳转到密码及完成输入。
- 运行环境页以中文检测项目显示结果，原始技术报告由用户展开，不在首屏直接显示 JSON；两项操作名为“检查本地环境”和“检查网络连接”。
- 原创“宿舍＋灯光＋确认”图标覆盖启动器和界面，提供 Android 24/25 常规图标、26+ 自适应图标及 33+ 单色主题图标；不使用学校校徽或额外图标依赖。

图标源文件和设计预览见 [视觉资源](../../android/artwork/README.md)。预览使用 debug-only 页面与合成账号，调用同一套界面组件，不联网或调用签到控制器；该页面不得进入正式 APK。
